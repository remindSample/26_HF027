## 작업 내용

* 변경된 기능이나 작업 내용을 작성합니다.
* 실제 코드 변경 사항을 기준으로 작성합니다.
* 서로 관련된 변경 사항은 하나의 항목으로 묶습니다.

## 주요 변경 파일

* `파일 경로`: 해당 파일에서 변경된 내용을 작성합니다.
* `파일 경로`: 해당 파일에서 변경된 내용을 작성합니다.

## 확인 사항

* 리뷰어가 중점적으로 확인해야 할 내용을 작성합니다.
* 화면 동작, 라우팅, API 연결 등 확인이 필요한 부분을 작성합니다.

## 테스트

* 실행한 테스트 또는 검사 명령을 작성합니다.
* 테스트를 실행하지 않았다면 `별도의 자동화 테스트는 실행하지 않음`이라고 작성합니다.

## 참고 사항

* 추가 작업이 필요한 부분이나 전달할 내용을 작성합니다.
* 특별한 내용이 없다면 `없음`이라고 작성합니다.
