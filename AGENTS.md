# Project Instructions

Before making UI, API, or data model changes, read and follow:

- specs/design.md

Before modifying any existing file, read and follow:

- specs/editing-guidelines.md
- specs/safe-editing-rules.md

## Pull Request

When the user asks to create, open, or submit a pull request, use:

- `.agents/skills/create-pr/SKILL.md`

Pull requests must target the `develop` branch unless the user explicitly specifies otherwise.
Do not create pull requests directly from `main` or `develop`.
