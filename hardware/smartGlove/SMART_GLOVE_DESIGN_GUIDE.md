# ReMind 스마트 장갑 최종 설계서 및 제작 지침

## 1. 목표

ReMind 손동작 게임의 임시 화면 버튼 4개를 하드웨어 장갑 입력으로 대체한다.

현재 게임 입력 구조는 다음 형태를 유지한다.

```ts
handleInput(hand: "LEFT" | "RIGHT", gesture: "FIST" | "PALM")
```

하드웨어 장갑은 이 함수에 들어갈 `hand`와 `gesture` 값을 무선으로 앱에 전달하는 입력 장치다. 게임 판정 로직은 장갑 제작과 분리한다.

최종 목표 흐름은 다음과 같다.

```text
왼손 장갑 센서값 → 왼손 ESP32 → BLE → Expo 앱 → handleInput("LEFT", gesture)
오른손 장갑 센서값 → 오른손 ESP32 → BLE → Expo 앱 → handleInput("RIGHT", gesture)
```

## 2. 최종 제작 방향

양손 모두 3센서 방식으로 제작한다.

```text
왼손: 검지, 중지, 약지 센서 3개
오른손: 검지, 중지, 약지 센서 3개
```

소지는 제외한다. 현재 게임은 `FIST`와 `PALM`만 필요하므로 3센서로 충분하다.

3센서 판정 기준:

```text
굽힌 손가락 2개 이상 → FIST
굽힌 손가락 0~1개 → PALM
```

## 3. 보유 부품 기준 구성

### 3.1 핵심 부품

팀에서 구매한 부품 기준:

```text
FireBeetle ESP32 DFR0478 보드 4개
3.7V 2000mAh LiPo 배터리 4개
54mm 플렉스 압력 센서 여러 개
47kΩ 저항 10개
저항 키트: 220Ω, 470Ω, 1kΩ, 4.7kΩ, 10kΩ
브레드보드 1개
점퍼선 Female/Male, Male/Male
단선 전선 3색
절연테이프
글루건, 핫멜트 스틱
흰 면장갑 여러 켤레
검정 작업 장갑 1개
납땜 인두, 납
```

### 3.2 한 손당 필요 수량

```text
FireBeetle ESP32 1개
LiPo 배터리 1개
54mm 플렉스 센서 3개
47kΩ 저항 3개
전선 여러 가닥
장갑 1쪽
절연테이프
글루건
```

### 3.3 양손 제작 시 필요 수량

```text
FireBeetle ESP32 2개
LiPo 배터리 2개
54mm 플렉스 센서 6개
47kΩ 저항 6개
장갑 1켤레
```

47kΩ 저항 10개가 있으므로 양손 3센서 제작에 충분하다. 남는 4개는 예비로 둔다.

## 4. 장갑 선택 기준

### 4.1 프로토타입

1차 제작은 흰 면장갑으로 진행한다.

이유:

```text
수량이 많아 실패해도 부담이 적다.
센서 위치 수정이 쉽다.
바느질, 테이핑, 글루건 작업이 쉽다.
팀원들이 동시에 테스트하기 좋다.
```

### 4.2 최종 시연용

최종 시연용은 검정 작업 장갑 1켤레를 추가 확보하는 것을 권장한다.

현재 검정 장갑은 1개뿐이라 양손 세트로 만들기 어렵다. 오른손만 검정, 왼손은 흰색이면 시연 완성도가 떨어질 수 있다.

권장 순서:

```text
1차: 흰 면장갑 오른손 3센서
2차: 흰 면장갑 왼손 3센서
3차: 동작 검증 후 검정 작업 장갑 1켤레로 최종 제작
```

## 5. 물리 배치 설계

### 5.1 손가락 센서 위치

플렉스 센서는 손바닥 쪽이 아니라 손등 쪽에 부착한다.

```text
검지 등쪽 중앙
중지 등쪽 중앙
약지 등쪽 중앙
```

센서 부착 원칙:

```text
센서 양 끝만 고정한다.
센서 가운데 감지부는 접착하지 않는다.
손가락을 굽힐 때 센서가 자연스럽게 휘어야 한다.
센서가 관절에서 과하게 꺾이지 않게 한다.
```

### 5.2 ESP32 위치

ESP32는 손등 중앙 또는 손등에서 손목에 가까운 위치에 둔다.

권장 방식:

```text
천 주머니를 만들어 ESP32를 넣는다.
USB 포트는 바깥쪽으로 노출한다.
보드 탈착이 가능하게 한다.
```

비추천:

```text
ESP32를 글루건으로 보드 전체에 직접 고정
USB 포트를 막는 위치에 부착
손가락 관절 위에 부착
```

### 5.3 배터리 위치

배터리는 손목 쪽에 둔다.

권장 방식:

```text
손목 부분에 배터리 주머니 제작
배터리는 접히는 위치에 두지 않기
충격을 덜 받는 위치에 고정
```

주의:

```text
LiPo 배터리에 직접 납땜하지 않는다.
배터리를 접거나 구멍 내지 않는다.
배터리 팩에 글루건을 과하게 바르지 않는다.
```

## 6. 전기 회로 설계

### 6.1 기본 회로

플렉스 센서는 저항값 변화 부품이므로 ESP32가 읽을 수 있도록 전압 분배 회로를 구성한다.

센서 1개당 회로:

```text
3.3V ─ 플렉스 센서 ─┬─ ESP32 아날로그 입력 핀
                    │
                  47kΩ
                    │
                   GND
```

중요:

```text
센서 전원은 3.3V를 사용한다.
ESP32 아날로그 핀에 5V를 넣지 않는다.
```

### 6.2 한 손 3센서 회로

```text
검지 센서 중간점 → A0 또는 GPIO34 계열 ADC 핀
중지 센서 중간점 → A1 또는 GPIO35 계열 ADC 핀
약지 센서 중간점 → A2 또는 GPIO36 계열 ADC 핀

각 센서 반대쪽 → 3.3V 공통
각 47kΩ 저항 아래쪽 → GND 공통
```

현재 테스트 코드에는 다음 핀을 읽는 구조가 들어 있다.

```cpp
analogRead(36)
analogRead(39)
analogRead(34)
analogRead(35)
```

3센서 제작에서는 이 중 3개만 사용하면 된다. 예:

```text
검지 → GPIO36
중지 → GPIO39
약지 → GPIO34
```

핀 이름은 실제 FireBeetle 보드의 실크 인쇄와 업로드 환경에서 확인한다.

### 6.3 저항 선택

기본값은 47kΩ을 사용한다.

```text
1차 테스트: 47kΩ
값 변화가 너무 작으면: 10kΩ으로 재테스트
```

멀티미터가 없으므로 ESP32 Serial Monitor로 값 변화를 확인한다.

## 7. 납땜 및 절연 지침

### 7.1 플럭스가 없는 상황

플럭스가 없어도 작업은 가능하다. 다만 납이 잘 안 붙을 수 있으므로 다음 순서를 지킨다.

```text
인두 충분히 예열
센서 단자에 먼저 소량의 납 묻히기
전선 끝에도 먼저 납 묻히기
두 지점을 맞대고 짧게 가열
한 단자에 오래 열을 가하지 않기
```

플렉스 센서는 열에 약할 수 있으므로 한 단자당 2~3초 안에 납땜을 끝내는 것을 목표로 한다.

### 7.2 절연 방식

수축튜브가 없으므로 절연테이프와 글루건을 함께 사용한다.

권장:

```text
납땜부를 절연테이프로 1차 감싸기
그 위를 글루건으로 얇게 보강
전선이 꺾이는 시작점에 글루건 점고정
```

주의:

```text
센서 감지부 전체를 글루건으로 덮지 않는다.
글루건으로 전선을 완전히 딱딱하게 만들지 않는다.
손가락 관절 부근에는 전선 여유를 둔다.
```

## 8. 제작 순서

### 8.1 목요일 팀 작업 목표

목요일 팀 작업의 목표는 완성품 제작이 아니라 다음 상태까지 검증하는 것이다.

```text
한 손 3센서 동시 읽기
Serial Monitor에 PALM/FIST 출력
장갑에 임시 고정 후 착용 상태에서 값 확인
```

### 8.2 상세 순서

1. FireBeetle ESP32 1개를 USB로 연결한다.
2. 브레드보드에 센서 1개 + 47kΩ 회로를 다시 구성한다.
3. Serial Monitor에서 값이 정상적으로 변하는지 확인한다.
4. 센서 3개로 확장한다.
5. 손 펴기 상태의 3개 값을 기록한다.
6. 주먹 상태의 3개 값을 기록한다.
7. 각 손가락 threshold를 계산한다.
8. 3센서 기준 `PALM` / `FIST` 문자열이 출력되게 한다.
9. 흰 장갑에 센서 3개를 임시 부착한다.
10. 착용 상태에서 값이 안정적인지 확인한다.
11. 안정적이면 납땜형 회로로 옮긴다.
12. 왼손도 같은 방식으로 반복한다.

## 9. 캘리브레이션 기준

멀티미터가 없으므로 캘리브레이션은 Serial Monitor 값으로 한다.

각 손가락마다 다음 값을 기록한다.

```text
openValue: 손을 편 상태 값
fistValue: 주먹을 쥔 상태 값
threshold = (openValue + fistValue) / 2
```

값 방향은 센서 배선에 따라 다를 수 있다.

```text
굽혔을 때 값이 커질 수도 있다.
굽혔을 때 값이 작아질 수도 있다.
```

따라서 펌웨어에서는 방향을 확인한 뒤 다음처럼 판정한다.

```text
값이 커지는 배선: value > threshold 이면 bent
값이 작아지는 배선: value < threshold 이면 bent
```

3센서 손동작 판정:

```text
bentCount >= 2 → FIST
bentCount <= 1 → PALM
```

오입력을 줄이기 위해 같은 gesture가 100~200ms 이상 유지될 때만 전송한다.

## 10. 펌웨어 설계

### 10.1 단계별 구현

BLE부터 붙이지 않는다. 먼저 USB Serial로 안정화한다.

```text
1단계: 센서 3개 analogRead
2단계: PALM/FIST 판정
3단계: Serial 출력
4단계: BLE notify 출력
```

### 10.2 Serial 출력 형식

왼손 펌웨어:

```text
LEFT,PALM,1200,1180,1220
LEFT,FIST,2900,3050,2880
```

오른손 펌웨어:

```text
RIGHT,PALM,1190,1210,1170
RIGHT,FIST,3010,2950,2870
```

### 10.3 BLE 전송 형식

앱 연동을 단순하게 하기 위해 최종 BLE 메시지는 문자열로 시작한다.

```text
LEFT,FIST
LEFT,PALM
RIGHT,FIST
RIGHT,PALM
```

디버깅이 필요할 때만 센서값을 붙인다.

```text
LEFT,FIST,2900,3050,2880
```

## 11. Expo 앱 연동 지침

### 11.1 기존 게임 로직 유지

게임 로직은 다음 입력 함수 중심으로 유지한다.

```ts
handleInput(hand: "LEFT" | "RIGHT", gesture: "FIST" | "PALM")
```

화면 버튼도 유지한다.

```text
BLE 연결됨 → 장갑 입력 사용
BLE 연결 안 됨 → 화면 버튼으로 테스트
```

### 11.2 앱 연결 구조

BLE 관점:

```text
ESP32 장갑 = BLE Peripheral
Expo 앱 = BLE Central
```

휴대폰 설정에서 이어폰처럼 페어링하는 구조가 아니라, 앱이 BLE 장치를 스캔하고 연결한다.

앱 흐름:

```text
장갑 연결 화면 진입
BLE 권한 요청
ReMind Left Glove 스캔
ReMind Right Glove 스캔
각 장갑 characteristic notify 구독
메시지 수신
handleInput(hand, gesture) 호출
```

### 11.3 iPhone / Android 테스트 전략

최종 목표가 iPhone이어도 된다. 다만 개발 초반 BLE 테스트는 Android가 더 수월하다.

권장:

```text
1차 BLE 테스트: Android
Expo 앱 BLE 연결 개발: Android
최종 시연 전 iPhone Development Build 테스트
```

Expo Go만으로 BLE native module 테스트는 어렵다. 실제 앱 BLE 연동에는 Development Build가 필요하다.

## 12. AWS / 백엔드 판단

장갑이 직접 AWS로 데이터를 보내는 구조는 사용하지 않는다.

권장 구조:

```text
장갑 → BLE → 휴대폰 Expo 앱 → 게임 입력
게임 결과 → Expo 앱 → FastAPI 백엔드 → DB
```

AWS는 나중에 FastAPI 백엔드를 배포할 때 고려한다. 실시간 손동작 입력은 BLE로 휴대폰 앱에 직접 전달한다.

## 13. 안전 지침

LiPo 배터리:

```text
구멍 내지 않기
접지 않기
직접 납땜하지 않기
극성 확인 전 연결하지 않기
충전 중 장갑 착용하지 않기
```

ESP32:

```text
3.3V 센서 회로 사용
5V를 ADC 핀에 넣지 않기
USB 포트 막지 않기
업로드 중 배터리 연결 상태 확인
```

납땜:

```text
환기
화상 주의
센서 단자 장시간 가열 금지
납땜 후 반드시 절연
```

장갑 착용:

```text
노출된 납땜부가 피부에 닿지 않게 하기
전선이 손가락을 조이지 않게 하기
배터리가 손목을 압박하지 않게 하기
```

## 14. 목요일 팀 회의 체크리스트

### 14.1 가져와야 할 것

```text
FireBeetle ESP32 보드
LiPo 배터리
플렉스 센서
47kΩ 저항
브레드보드
점퍼선
흰 면장갑
납땜 인두
납
절연테이프
글루건
노트북
USB 케이블
Android 테스트폰
iPhone 테스트폰
```

### 14.2 현장에서 확인할 것

```text
배터리 커넥터가 FireBeetle 보드에 맞는가
배터리 극성이 맞는가
ESP32 업로드 포트가 잡히는가
센서 1개 값이 읽히는가
센서 3개 값이 동시에 읽히는가
손 펴기/주먹 값 차이가 충분한가
장갑 착용 상태에서 센서값이 안정적인가
```

### 14.3 목요일 완료 기준

최소 완료 기준:

```text
오른손 3센서가 Serial Monitor에서 PALM/FIST 출력
```

권장 완료 기준:

```text
왼손/오른손 모두 3센서가 Serial Monitor에서 PALM/FIST 출력
```

확장 완료 기준:

```text
BLE notify로 LEFT,FIST / RIGHT,PALM 형식 전송
```

## 15. 팀 역할 분담 제안

```text
하드웨어 1명: 센서/저항/ESP32 회로 구성
하드웨어 1명: 장갑 부착, 배선 정리, 절연
펌웨어 1명: analogRead, threshold, Serial 출력
앱 1명: BLE 연결 화면과 handleInput 연결 준비
기록 1명: 센서값, 핀맵, 문제 상황 문서화
```

## 16. 미확정 사항

제품 도착 후 확인해야 하는 사항:

```text
LiPo 배터리 커넥터가 FireBeetle 포트에 맞는지
배터리 극성이 맞는지
보드 실크 인쇄 기준 실제 ADC 핀 이름
굽혔을 때 센서값이 증가하는지 감소하는지
흰 장갑으로 착용 안정성이 충분한지
최종 검정 장갑 1켤레를 추가 구매할지
```

## 17. 최종 결정 요약

```text
장갑: 양손 3센서 방식
센서 위치: 검지, 중지, 약지
보드: 손등 주머니
배터리: 손목 주머니
저항: 센서당 47kΩ 1개
```
